## Shipped with pdf.js

These files are copied from `pdfjs-dist` into the built app, so PDFs render without fetching anything from other sites:

| Files | Licence | Licence text in the built app |
| --- | --- | --- |
| Foxit standard fonts (`Foxit*.pfb`) | BSD-style (PDFium Authors) | `vendor/pdfjs/standard_fonts/LICENSE_FOXIT` |
| Liberation Sans fonts (`LiberationSans-*.ttf`) | GNU GPL v2 with the Liberation font exception (documents that use or embed the fonts are not covered by the GPL) | `vendor/pdfjs/standard_fonts/LICENSE_LIBERATION` |
| Adobe CMaps (`cmaps/*.bcmap`) | BSD-3-Clause (Adobe) | `vendor/pdfjs/cmaps/LICENSE` |
| pdf.js WebAssembly image decoders (`wasm/`) | See the pdf.js repository | — |

The fonts and CMaps are used only to show PDFs on screen. The app doesn't modify them.

## Development only

The tools used to build and test the project (Vite, TypeScript, ESLint, Prettier, Vitest, Playwright, axe-core, pdf-lib and others) aren't shipped in the app. Their licences are in each package under `node_modules` after `pnpm install`.

Every PDF, company, person, ABN and number in `fixtures/` is made up for testing. None comes from a real business.
